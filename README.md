🧑‍💻 Tools & Tech

MySQL

📌 Project Overview

This project predicts customer churn and provides business insights to help telecom companies reduce customer loss.
It includes:
✔ Data Analysis in SQL
✔ EDA & Machine Learning in Python
✔ Interactive Power BI Dashboard
✔ Churn Probability Risk Scoring

📊 Power BI Dashboard

Insights delivered:

Churn Rate

Churn by Contract Type

Churn by Tenure

Churn by Monthly Charges

Churn by Payment Method

High Risk Customers (Predicted by ML)

🤖 Machine Learning Model

Logistic Regression (baseline)

Random Forest (final selected model)

📌 Random Forest performed better:

Accuracy: ~79%

Churn Recall improved from 30% → 44%

🧠 Key Business Insights

Month-to-Month customers churn highest

Low tenure customers churn more

High monthly bill leads to churn

Electronic Check customers churn more

Yearly contract customers are loyal

🚀 Predictive Power

Each customer gets a Churn Probability Score
Used to identify:

High Risk (>60%)

Medium Risk

Low Risk

Displayed inside Power BI dashboard.
